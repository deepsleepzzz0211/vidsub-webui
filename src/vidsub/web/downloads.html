    识别模型使用网易自定义协议（不是 Apache 2.0），协议全文随权重一起保存到本机。 默认从 ModelScope 下载。

    下载很慢或连不上？

    默认直连下载 —— 实测 ModelScope 直连约 21 MB/s，走代理反而只有 240 KB/s。
    只有 GitHub 例外：VAD 模型在 GitHub 上，直连会在中途截断，所以自动走代理。
    若你的网络需要手动指定，下载前设这些环境变量再启动 vidsub：

    VIDSUB_DOWNLOAD_PROXY=http://127.0.0.1:7897 —— 指定代理地址
    VIDSUB_FORCE_DIRECT=0 —— 全部走代理（墙内）
    VIDSUB_PROXY_HOSTS=mirror.example.com —— 追加需要走代理的域名
    VIDSUB_DOWNLOAD_TIMEOUT=120 —— 单次请求超时秒数

    直连失败会自动回退代理一次，并记住这个域名，不再重复卡超时。
